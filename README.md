# Dilshad v1 Website Concept

A fast static v1 concept for a redesigned Dilshad Restaurant site, deployable on GitHub Pages.

## Goals
- Cleaner brand-forward UX
- Strong conversion to online ordering
- Easy integration with existing ordering provider

## Ordering Integration
The order CTA is configured in `script.js` via:

```js
const ORDER_URL = 'https://dilshadrestau.com/order';
```

Swap this URL to your production ordering endpoint/provider when ready.

## Local Preview
Open `index.html` directly or serve folder with any static server.

## Deploy
Push to GitHub and enable Pages from `main` branch root.
