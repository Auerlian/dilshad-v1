# Dilshad Restaurant Website

A clean, premium, and luxury restaurant website with modern design inspired by Kasa Sushi.

## 🎯 Features

- **Clean Design**: Minimalist interface with focus on food and user experience
- **Light/Dark Theme**: Toggle between light and dark modes
- **Responsive**: Works perfectly on desktop, tablet, and mobile
- **Fast Ordering**: Streamlined menu with inline cart management
- **Easy Reservations**: Simple booking form with WhatsApp integration
- **Premium Aesthetic**: Sophisticated typography and spacing

## 📄 Pages

1. **Home** (`index.html`) - Welcome page with hero, features, and popular dishes
2. **Menu** (`menu.html`) - Full menu with ordering system and floating cart
3. **Reservations** (`reservations.html`) - Table booking form
4. **Contact** (`contact.html`) - Contact information and map

## 🎨 Design

- **Colors**: Light theme with gold accents (dark mode available)
- **Typography**: Playfair Display (headings) + Inter (body)
- **Layout**: Clean grid system with generous whitespace
- **Components**: Minimal cards, smooth transitions, elegant forms

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Browse the menu at `menu.html`
3. Book a table at `reservations.html`
4. Find us at `contact.html`

## 📱 Features

- Location selection before ordering
- Sticky category navigation
- Real-time cart updates
- WhatsApp order integration
- Theme persistence (localStorage)
- Scroll spy navigation
- Mobile-optimized interface

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties)
- Vanilla JavaScript
- No frameworks or dependencies
